## Summary

BSE has announced the rollout of NFCAST Market Data API Version 6.3 in the Equity Derivatives Segment, effective Monday, December 7, 2026. This update incorporates changes related to the review of the Closing Auction Session (CAS), market timings, and settlement methodology for derivatives contracts.

## Key Points

- NFCAST Market Data API Version 6.3 will go live in the Equity Derivatives Segment on December 7, 2026.
- Includes a minor change in Message 2028 specific toோர் the Equity Derivatives Segment.
- Updated API documentation is available on the BSE website and in the simulation environment for testing.
- Trading members and front-end application vendors must update their applications accordingly.

## Regulatory Changes

- Updates to support changes in the Closing Auction Session (CAS), market timings, and settlement methodology as outlined in prior circulars (20261019-44 and 20261016-14).
- Minor adjustment in Message 2028 for equity derivatives data feeds.

## Compliance Requirements

- Trading members and front-end trading application vendors must integrate NFCAST API Version 6.3 into their systems.
- Conduct necessary testing in the exchange simulation environment prior to the live rollout.

## Important Dates

- **Effective Date:** December 7, 2026 (Live rollout in Equity Derivatives Segment).
- **Notice Date:** November 21, 2026.

## Impact Assessment

Operational impact is medium for trading members and algorithm/front-end vendors who must update API parsers for Message 2028 and align with updated derivatives market timings and CAS rules.
