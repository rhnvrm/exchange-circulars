## Summary

BSE has announced the availability of the penalty report for client code modifications of non-institutional trades for October 2026. Trading members are required to download and save the file for future reference.

## Key Points

- Penalty report for client code modifications of non-institutional trades during October 2026 is now available.
- File name: PM1026.Clg
- Location: EQUITY TRANSACTION FOLDER in Extranet.
- Based on Exchange Notice Nos. 20110729-24 and 20110826-4.

## Regulatory Changes

- No new regulatory changes; routine monthly report download as per existing guidelines.

## Compliance Requirements

- Trading members must download, save, and review the penalty report (`PM1026.Clg`) from the Extranet EQUITY TRANSACTION FOLDER for future reference and compliance verification.

## Important Dates

- Notice Date: 11 November 2026
- Period Covered: October 2026

## Impact Assessment

- Operational notice directing members to access penalty reports for non-institutional client code modifications. Low market impact.
