## Summary

BSE has announced the release of a new version of the BOLT Pro Trading Workstation (TWS) ver. 13.75, effective from Tuesday, November 3, 2026. This version update is optional and applies to Equity, Equity Derivatives, Currency Derivatives, Commodity Derivatives, and EGR segments.

## Key Points

- New Version: BOLT Pro TWS ver. 13.75.
- Effective Date: Tuesday, November 3, 2026.
- Release Type: Optional version release.
- Applicable Segments: Equity, Equity Derivatives, Currency Derivatives, Commodity Derivatives, and EGR.
- Enhancements: Includes technical enhancements.

## Regulatory Changes

None. This is an operational software release for trading members.

## Compliance Requirements

Trading members can optionally upgrade to BOLT Pro TWS ver. 13.75 via the Auto-Download Interface (for Leased Line connection users) or by downloading 'Software Update.zip' from the BSE help website and following installation instructions.

## Important Dates

- Download Start Date: November 02, 2026, from 7:00 PM onwards.
- Effective Date: November 03, 2026.

## Impact Assessment

Minimal operational impact since the release is optional, providing technical improvements for trading members using the BOLT Pro TWS platform.
