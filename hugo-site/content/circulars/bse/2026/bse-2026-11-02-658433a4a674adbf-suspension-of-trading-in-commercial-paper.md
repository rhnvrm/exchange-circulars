## Summary

BSE has issued a notice informing trading members that several companies have fixed record dates for the redemption of Commercial Papers (CPs). Trading members are advised not to deal in the commercial papers of the specified companies starting from the respective ex-dates and record dates.

## Key Points

- **Segment:** Debt Segment (Listing Operations)
- **Purpose:** Record date fixed for redemption of Commercial Papers.
- **Action Required:** Trading members are advised not to deal in the CPs of listed companies as per the schedule.

## Issuing Entities and Schedule

- **Julius Baer Capital (India) Private Limited:** Scrip Codes 732154, 732276, 732304 (Record Dates: 05/11/2026, 11/11/2026, 13/11/2026)
- **Standard Chartered Securities (India) Limited:** Scrip Code 732250 (Record Date: 05/11/2026)
- **Nexus Select Trust:** Scrip Code 732675 (Record Date: 05/11/2026)
- **L&T Metro Rail (Hyderabad) Limited:** Scrip Code 732255 (Record Date: 07/11/2026, Ex Date: 06/11/2026)
- **Avenue Supermarts Limited:** Scrip Code 732272 (Record Date: 06/11/2026)
- **Aditya Birla Lifestyle Brands Limited:** Scrip Code 732292 (Record Date: 10/11/2026, Ex Date: 09/11/2026)
- **The Bombay Burmah Trading Corporation Ltd.:** Scrip Code 730548 (Record Date: 11/11/2026)
- **Redington Limited:** Scrip Codes 732297, 732298 (Record Dates: 11/11/2026 and 12/11/2026)
- **Indian Oil Corporation Ltd.:** Scrip Code 732767 (Record Date: 12/11/2026)
- **Infina Finance Private Limited:** Scrip Code 730600 (Record Date: 16/11/2026)
- **Muthoot Mcred Limited:** Scrip Code 731701 (Record Date: 16/11/2026)
- **360 ONE Alternates Asset Management Limited:** Scrip Code 731722 (Record Date: 16/11/2026)
- **ICICI Home Finance Company Limited:** Scrip Code 732317 (Record Date: 16/11/2026)
- **Godrej Housing Finance Limited:** Scrip Code 732321 (Record Date: 16/11/2026)

## Regulatory Changes

None. Routine administrative notice regarding commercial paper redemption and suspension of trading.

## Compliance Requirements

Trading members must ensure compliance by refraining from dealing in the commercial papers of the aforementioned entities on or after the specified ex-dates / record dates.

## Important Dates

- **Record Dates:** November 5, 2026 through November 16, 2026
- **Ex-Dates:** November 5, 2026 through November 16, 2026

## Impact Assessment

Ensures orderly settlement and redemption of commercial papers in the debt segment by halting secondary market trading as maturities are reached.
