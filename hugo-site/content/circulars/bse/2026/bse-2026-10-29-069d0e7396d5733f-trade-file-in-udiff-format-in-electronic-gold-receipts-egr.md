## Summary

BSE has announced the introduction of the Trade file in Unified Distilled File Format (UDiFF) for the Electronic Gold Receipts (EGR) segment. The new UDiFF trade files will go live on November 02, 2026.

## Key Points

- UDiFF format introduced for EGR segment trade files.
- Existing provision and final trade file formats will run in parallel with UDiFF files until December 04, 2026.
- Post December 04, 2026, trade files will be available exclusively in UDiFF format.
- Files will be available for download on the Extranet after the close of EGR trading.

## Regulatory Changes

- Transition of EGR segment trade files to the standardized Unified Distilled File Format (UDiFF).

## Compliance Requirements

- Trading members participating in the EGR segment must update their internal systems to support and process the new UDiFF trade file format before the parallel run ends.

## Important Dates

- **Go-Live Date:** November 02, 2026
- **Parallel Run End Date:** December 04, 2026

## Impact Assessment

- Operational impact is low, requiring trading members to adapt their ingestion pipelines to the UDiFF format during the designated parallel run window.
