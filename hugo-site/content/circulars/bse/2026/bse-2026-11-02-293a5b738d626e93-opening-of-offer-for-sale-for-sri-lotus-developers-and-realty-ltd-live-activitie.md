## Summary

BSE has issued a notice regarding the live activities schedule for the Offer for Sale (OFS) of shares of Sri Lotus Developers and Realty Ltd (Security Symbol: LOTUSDEV, ISIN: INE0V9Q01010). The base offer size is 2,37,95,818 shares with an additional oversubscription option of up to 50,00,000 shares.

## Key Points

- Security Name: SRI LOTUS DEVELOPERS AND REALTY LTD
- Security Symbol: LOTUSDEV | Security Code: 544469 | ISIN: INE0V9Q01010
- Total Base Offer Size: 2,37,95,818 shares (with an oversubscription green shoe option of up to 50,00,000 shares)
- Retail Allocation: 10% of the issue size (23,79,582 shares base offer size plus 5,00,000 shares oversubscription option)
- Non-Retail Allocation: 2,14,16,236 shares base offer size plus 45,00,000 shares oversubscription option
