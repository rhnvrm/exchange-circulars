## Summary

National Stock Exchange of India Limited (NSE) will conduct a mock trading session in the Securities Lending and Borrowing Market (SLBM) segment on Saturday, November 14, 2026. There is no new software version release for this session.

## Key Points

- Mock Date: November 14, 2026.
- Normal Market open time: 12:15 Hrs; close time: 14:30 Hrs.
- Live Re-login start time: 16:00 Hrs; close time: 16:30 Hrs.
- All outstanding orders will be cleared before each session; members using NNF software must manually clear orders.
- Trades during mock sessions will not result in any fund pay-in or pay-out.
- Only valid and compliant UCC/PAN uploaded and approved before cutoff will be allowed.
- NOTIS application will be accessible during the mock trading session.

## Regulatory Changes

No regulatory changes; this is a routine operational mock trading session.

## Compliance Requirements

- Members should participate using all trading software and re-login into the live environment to ensure smooth connectivity for Monday, November 16, 2026.
- Ensure appropriate branch and user limits are set from the Corporate Manager Terminal before placing orders.
- Ensure valid and compliant UCC/PAN details are uploaded.

## Important Dates

- Mock Trading Date: November 14, 2026
- Live Re-login Timings: November 14, 2026, 16:00 Hrs to 16:30 Hrs
- Resume Live Trading: November 16, 2026

## Impact Assessment

Minimal operational impact. The session helps trading members verify connectivity, Box ID setup, and NNF application readiness without financial obligations.
