## Summary

NSE Clearing Limited has announced the extension of a bid confirmation facility to Custodians for bids executed in Tender Offers (OTB) using the Custodial Participant (CP) code in the N-MASS application, effective November 27, 2026.

## Key Points

- Extension of bid confirmation facility in N-MASS for Tender Offer (OTB) bids to Custodians.
- Role management update required: Custodians must assign the “Tender Offer” service through the role management menu under NMASS.
- File-based confirmation functionality allows generating and uploading order confirmation files based on symbol and settlement number.
- File nomenclature specified for both generated order files and upload files.
- Batch numbers will be incremental for the trade date, and approval/rejection flags ('Y'/'N') must be specified in the upload file.

## Regulatory Changes

- Introduction of mandatory role management and file confirmation/rejection workflow for custodians participating in tender offer bids on N-MASS.

## Compliance Requirements

- Custodians must update user roles to include the "Tender Offer" service.
- Custodians must utilize the NMASS application within defined confirmation windows to generate, review, and upload confirmation/rejection files.

## Important Dates

- **Effective Date:** November 27, 2026.

## Impact Assessment

- Streamlines operational reconciliation and confirmation workflows for custodians handling tender offer bids on NSE Clearing Limited.
