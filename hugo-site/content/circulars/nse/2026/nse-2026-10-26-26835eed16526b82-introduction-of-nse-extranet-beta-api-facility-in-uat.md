## Summary

The National Stock Exchange (NSE) has announced the introduction of the NSE Extranet Beta API facility for testing in the User Acceptance Testing (UAT) environment, following up on circular NSE/MSD/73589 dated April 02, 2026. Trading members can now register sub-users and test API endpoints across various segments (CD, CM, CO).

## Key Points

- **Facility:** NSE Extranet Beta API facility available for testing in UAT.
- **API Version:** Members calling the endpoints in UAT must input version as `1.0`.
- **Documentation & Guides:** Includes API specifications, Member Portal admin user guides for sub-user creation, sub-user registration guides, and a list of sample test files.
- **Access:** Existing Member Portal admin users in live have automatic access to the UAT Member Portal.
- **Go-Live:** The official go-live date will be communicated via a separate circular.

## Regulatory Changes

No direct regulatory change or compliance penalty; this is an operational technology upgrade and testing facility for exchange extranet access via APIs.

## Compliance Requirements

- Member Portal administrators must create sub-users in the UAT Member Portal as per Annexure 2.
- Sub-users must follow Annexure 3 to complete API registration in UAT for testing purposes.

## Important Dates

- **Circular Date:** October 26, 2026
- **Go-Live Date:** To be announced separately

## Impact Assessment

Trading members, technical teams, and API developers can test automated file retrieval and extranet interactions via the new Beta API facility in UAT, improving operational efficiency and technical readiness ahead of the live launch.
