## Summary

NSE has revised the release date for the dissemination of a separate market making compliance file containing data for SME scrips traded in the Periodic Call Auction Session (PCAS) Market. The new implementation date is November 16, 2026.

## Key Points

- Revises previous circular NSE/SURV/77153 dated October 29, 2026.
- The compliance file will contain data for SME scrips traded in the Periodic Call Auction Session (PCAS) Market.
- File dissemination path: Extranet path (/cmftp/Onlinebackup) on an hourly basis.
- Revised release date: November 16, 2026.
- All other provisions of the earlier circular remain unchanged.

## Regulatory Changes

- Extension of the launch timeline for market making compliance file dissemination for SME scrips in PCAS.

## Compliance Requirements

- Members participating in market making for SME scrips in PCAS should note the revised release date of November 16, 2026, for hourly Extranet file availability.

## Important Dates

- October 30, 2026: Circular issuance date.
- November 16, 2026: Revised release date for market making compliance file dissemination.

## Impact Assessment

- Operational timeline adjustment for members tracking SME market making compliance data with minimal disruption.
