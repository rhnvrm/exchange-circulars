## Summary

National Stock Exchange (NSE) has announced the launch of E-IPO 2.0, introducing an upgraded authentication mechanism from session-based Access Token to JWT (JSON Web Token) Authentication along with new V3 API endpoints hosted on a new domain.

## Key Points

- The URL to access eIPO2.0 is https://bidcollection.nseindia.com/login.
- Authentication mechanism is upgraded to industry-standard JWT authentication for enhanced security.
- New V3 API endpoints are introduced on a new domain.
- Existing V1 APIs will be deprecated soon, while V2 APIs remain available.
- JWT tokens have an expiry period of 1 hour and must be refreshed using the Heartbeat API at the 58th minute.

## Regulatory Changes

- Implementation of industry-standard JWT authentication for eIPO APIs.
- Introduction of V3 API endpoints with new domain hosting.

## Compliance Requirements

- Market participants must modify their applications to implement JWT-based authentication for consuming new V3 API endpoints.
- Pass the JWT token returned by the Login API in the Authorization header (`Authorization: Bearer <JWT Token>`).
- Adopt new V3 APIs and migrate away from deprecated V1 APIs.

## Important Dates

- Go-live date and V1 API deprecation date will be communicated by the Exchange.

## Impact Assessment

- Improved security posture for eIPO transactions.
- Requires development effort for market participants to integrate JWT token management and V3 domain endpoints.
