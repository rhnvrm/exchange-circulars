## Summary

NSE Clearing has issued an update regarding the mechanism for reporting and monitoring currency derivative contracts involving INR, pursuant to SEBI circular HO/(561)2026-MRD-POD2/I/25177/2026 dated November 5, 2026, and earlier consolidated circulars.

## Key Points

- Details the format of letters from Authorised Dealer Category-I (AD-I) banks confirming appointment as designated banks for monitoring and reporting client positions in currency derivatives.
- Specifies role management access, file formats (upload nomenclature: `X_<MEMBERCODE>_ADBNK_MSTR_YYYYMMDD.Tnn` and response files `X_<MEMBERCODE>_ADBNK_MSTR_YYYYMMDD.S/Rnn`), and upload procedures in the NMass portal.
- Introduces the CD Position Limit Monitoring file format (`CD_PLM_DDMMYYYY_ADBANK_N.CSV`) to be provided to AD-I banks.

## Regulatory Changes

- Implements updated reporting structures and master file definitions for currency derivative contracts involving INR in coordination with SEBI guidelines and previous NCL circulars.

## Compliance Requirements

- Clearing members and designated AD-I banks must adhere to the specified master file nomenclature, record formats, and position limit monitoring file structures.

## Important Dates

- Circular date: November 06, 2026.

## Impact Assessment

- Affects clearing members, trading members, and AD-I banks handling currency derivative positions by establishing standardized reporting and monitoring file formats.
