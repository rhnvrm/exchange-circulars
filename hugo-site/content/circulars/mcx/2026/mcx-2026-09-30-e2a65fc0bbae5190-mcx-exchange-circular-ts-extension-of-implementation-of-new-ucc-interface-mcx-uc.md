## Summary

Multi Commodity Exchange of India Limited (MCX) has announced the extension of the implementation timeline for the new UCC Interface, covering MCX UCC File Formats (Version 1.1) and UCC-API (Version 1.0), which was previously set to take effect on October 05, 2026.

## Key Points

- Continuation of Circular No. MCX/S&I/546/2026 dated September 25, 2026.
- Implementation of Version 1.1 file formats and Version 1.0 UCC-API is deferred until further communication.
- Revised implementation dates will be published separately by the Exchange.

## Regulatory Changes

- Deferral of technical rollout deadlines for client code interface standards.

## Compliance Requirements

- Trading members and technology vendors are required to note the extension and await further circulars regarding updated timelines before deploying the new UCC interface integration.

## Important Dates

- **October 01, 2026**: Extension notice issued.
- **October 05, 2026**: Original effective date (deferred).
- **Future Date**: Revised rollout schedule to be communicated.

## Impact Assessment

- Alleviates immediate integration pressure on members and software vendors, allowing additional time for testing and seamless adoption of the new UCC API and file formats.
