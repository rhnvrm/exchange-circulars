## Summary

Multi Commodity Exchange of India Ltd (MCX) has issued an update regarding Computer to Computer Link (CTCL) facilities, amending Annexure 20 (Undertaking for In-house software development) to include clauses on CSCRF and Retail Algo. Additionally, a new requirement for a System Audit Certificate (Annexure 8) has been introduced for Independent Software Vendors (ISVs).

## Key Points

- Annexure 20 Undertaking for In-house software development has been amended to incorporate CSCRF and Retail Algo clauses.
- Introduction of an additional System Audit Certificate requirement (Annexure 8) for Independent Software Vendors (ISVs).
- Applications submitted up to April 29, 2026, using the previous Annexure 20 format will be accepted.

## Regulatory Changes

- Modifications to the Exchange CTCL Master Circular no. MCX/CTCL/223/2025.
- Updated compliance formats for software undertakings and ISV audit certifications.

## Compliance Requirements

- Trading members engaging in in-house software development for CTCL, IBT, WT, ATF, or DMA must execute the revised Annexure 20 undertaking.
- Independent Software Vendors must submit the mandated System Audit Certificate under Annexure 8.

## Important Dates

- Effective Date: April 30, 2026.
- Deadline for accepting old Annexure 20 format: April 29, 2026.

## Impact Assessment

- Trading members and software vendors must update their compliance documentation and audit submissions in alignment with the revised formats before the effective deadline.
