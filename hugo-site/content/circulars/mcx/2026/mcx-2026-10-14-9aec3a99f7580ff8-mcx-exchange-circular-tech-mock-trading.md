## Summary

Multi Commodity Exchange of India Ltd (MCX) has announced a mock trading session for members on Saturday, October 17, 2026. The session includes testing trading applications, Disaster Recovery (DR) site migration, and system restoration mechanisms.

## Key Points

- Mock trading session scheduled for Saturday, October 17, 2026.
- Special Session timing: 02:55 pm – 02:59 pm.
- Primary site mock trading timing: 03:00 pm – 06:00 pm.
- Exchange will abruptly disconnect trading from the primary site anytime between 05:55 pm to 06:00 pm for migration to the DR site.
- DR site mock trading timing: 07:00 pm – 08:00 pm.
- Members using CTCL facility are requested to participate using MCX Enhanced Trading Interface (ETI) API version 1.4.2 dated August 14, 2024.
- Connectivity available via existing leased lines or live SSL VPN link (https://trade.mcxindia.com).

## Regulatory Changes

No regulatory changes; this is a routine technical mock trading and disaster recovery drill conducted under exchange rules and bylaws.

## Compliance Requirements

- Members are requested to actively participate in the mock trading session using CTCL software and ETI API v1.4.2.
- Members must put in place an adequate mechanism to restore their trading systems to the production state at the end of the mock session to ensure system integrity.
- Trades resulting from mock trading will not attract any obligation for pay-in and pay-out.

## Important Dates

- Circular Date: October 15, 2026
- Mock Trading Date: October 17, 2026

## Impact Assessment

Operational drill with no financial or settlement impact. Ensures member trading applications, DR readiness, and connectivity protocols function seamlessly.
