## Summary

Metropolitan Stock Exchange of India Limited (MSEI) is conducting a mock trading session in the Equity Derivatives Segment on Saturday, November 21, 2026. Participation requires the mandatory installation of Trading Software Version 25.1 (MAT-Member Admin Terminal 25.1.2.0 and TWS-Trader Workstation 25.1.2.0).

## Key Points

- Mock Trading Date: Saturday, November 21, 2026.
- Software Version: MAT and TWS Version 25.1.2.0.
- Download Source: SFTP Server via https://sftp.mseindia.com (Derivatives COMMON\SETUP\Mock Setup folder).
- Live Environment Note: Members must use existing version 25.0.9.0 for live trading starting Monday, November 23, 2026.
- Mock trades do not attract any margin obligations, pay-in, pay-out, or create rights and liabilities.

## Regulatory Changes

- Mandatory technical upgrade release (Version 25.1) specifically for testing and mock trading session participation.

## Compliance Requirements

- Members must download and install VC++ Redistributable 2008 followed by MSE-EDSTWSCLIENT.msi and MSE-EDSMEMADMIN.msi for Version 25.1.2.0.
- Configure Leased Line or Internet connectivity parameters as specified in the circular instructions.
- Ensure active participation in the mock trading session.

## Important Dates

- Setup Download: Friday, November 20, 2026 (after trading hours).
- Mock Trading Session: Saturday, November 21, 2026.
- Live Trading Resume (Existing Version 25.0.9.0): Monday, November 23, 2026.

## Impact Assessment

Operational preparedness for equity derivatives members requiring temporary installation of mock trading software version 25.1 without impacting live trading systems on regular trading days.
